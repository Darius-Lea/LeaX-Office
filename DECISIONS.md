# Decisions
Start with zero third-party dependencies and Node built-in SQLite to establish durable local execution without paid accounts. Backend uses native TypeScript; frontend is temporarily plain JavaScript/HTML and must migrate incrementally toward the requested React architecture. No build tooling is needed for this foundation. Do not represent this deviation as the finished preferred stack.
Source availability is not lead discovery. Keep tasks blocked until an actual extraction connector exists. Keep all writes local and external operations read-only.
