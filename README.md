# AI Headquarters
Early local foundation for LeaX LLC / American Power Global. This is an incomplete Phase 1 application, not a finished business acquisition platform.

Requires Node 24.19+; no third-party runtime dependencies. Run `npm ci`, `npm test`, then `npm start` from the repository root. The server binds only to loopback port 4310. Use a local browser on the host machine. First launch prints a one-time setup code in its terminal; use it to choose a password of at least 14 characters. The cloud onboarding interface does not provide an application preview.

Run `npm run worker` in a second terminal only when you want processing. Stop with Ctrl+C. It persists each checkpoint and recovers expired 60-second leases. Tasks now query the public USAspending contract-award API, save historical award records and hand the evidence to Bravo for deterministic provenance review. Each assignment collects up to 3 pages of 20 records; failed pages preserve the checkpoint and show a Retry button. Award URLs deduplicate records across assignments. The UI shows source links, descriptions, locations and unverified qualification warnings. These are historical awards for potential-partner research, not open bids or confirmed leads. No inference is performed yet. Live collection in this cloud environment is blocked by API-domain network policy; fixture tests pass but no real records have been collected here.

Data stays in `data/headquarters.sqlite` with WAL sidecars; set HQ_DATA_DIR to an absolute private directory to relocate storage. Keep this folder across restarts. UI backup uses SQLite's online backup API. No automatic rotation or off-device backups yet. See DEPLOYMENT.md. No paid services or external accounts are required.

Windows users can manually opt in to the sign-in worker using scripts/windows-worker.ps1. The script is untested on Windows and is never run automatically. Ollama availability/model detection is exposed by the authenticated health endpoint, but inference and model selection are unfinished.

Research uses at most three service terms mapped from the goal (cabling, networking, low voltage, CCTV/security, data center, commercial AV, printers, POS); otherwise defaults to cabling/network installation/low voltage. No state/country restriction is applied, allowing nationwide and overseas US federal awards. This is not comprehensive international opportunity coverage. Existing founder credentials and data remain unchanged.

Render deployment: see DEPLOYMENT.md for port binding, exact HTTPS origin, private first-run HQ_SETUP_CODE and npm build settings. Render free web storage is ephemeral: founder credentials and business data do not survive reliably without a durable storage solution. Local operation remains the free durable option.

## Clock-in office (2026-10-21)
After signing in, click **Clock in**. The web server now processes saved research assignments internally; a separate worker service is unnecessary for this mode. When the queue is empty, it creates one assignment from the saved standing goal. While clocked in and awake, it refreshes standing-goal research every six hours when no work is pending. Clock out prevents new claims; an active page request may finish. A web-process restart clocks out safely; it does not delete assignments. Render free instances can sleep and still have ephemeral storage.

Edit Company & direction to use any company name/legal name and objective. Your owner workspace has no subscription employee cap. Six default employee configurations are provided, and you can add/rename/edit roles. Only Alpha's research and Bravo's deterministic review tools execute; other roles explicitly show Setup required. Names do not change tool permissions.

The rotatable CSS 3D office has clickable desks, employee markers, and indicators derived from actual task states. It is an initial architectural view, not a fully animated avatar simulation. Clerical and terminal-style views share the same records and controls; the view preference stays in the browser. Scroll below for forms, evidence and audit records. Inspect employees, edit unfinished objectives, and add owner review notes without replacing original source evidence.

Local startup remains npm ci, npm test, npm start with Node 24.19+ (24.x). Use Clock in in the browser; no terminal worker command is required. The optional standalone/Windows worker respects a clock-out setting when present. Do not run multiple worker modes unnecessarily. No sending, billing, purchases or new background OS registration is enabled.

## Owner inbox and connected team (2026-10-21)
Opening the signed-in app automatically clocks in unless you explicitly clicked Clock out. Clock state now persists across tab closure and process restart; Clock out remains authoritative across reloads. No browser tab is required after activation, but the host must be running. Render free sleep still stops all execution; this code cannot provide always-on infrastructure or durable free Render storage.

After completed Alpha/Bravo research, four deterministic internal jobs run: Juliet maintains a deduplicated recipient-company register, Hotel saves service-territory/capability checks, Delta creates vendor-introduction drafts (NOT SENT, To unknown), and Einstein prepares an owner briefing. They persist reports in Owner computer → Inbox with unread badges and mark-read controls. These tools are not language-model inference, and they never invent decision-maker contacts. The only external source is still historical federal awards. Searches now sort by Last Modified Date to prioritize recently updated awards, not proof of new open rollouts.

Main view emphasizes the office. Click Open owner computer for delivered notes; Company settings, employees & research files are collapsed below, available from the computer too. Employee figures now have heads/faces, bodies, arms and legs at their desks. This remains a CSS 3D architectural office rather than a full walking-avatar/WebGL simulation.
